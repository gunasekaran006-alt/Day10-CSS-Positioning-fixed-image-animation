# Image Hover Overlay Effect 🌲

This project showcases a modern, responsive **image hover animation** where an overlay text smoothly appears when a user hovers over the image. It uses pure HTML and CSS with advanced positioning and transition properties.

## ✨ Features
*   **Smooth Transitions:** Uses CSS `opacity` and `transform` for a professional feel.
*   **Responsive Design:** Fixed container size with `object-fit: cover` to maintain image aspect ratio.
*   **Perfect Centering:** Text is precisely centered using the `translate` method.
*   **Glassmorphism Touch:** Semi-transparent background for better text readability.

## 🛠️ Technologies Used
*   **HTML5** - For structure.
*   **CSS3** - For styling and animations.
